# Windows 软件下载安装

在这台 Windows 设备上下载或安装软件时，遵守用户的目录选择和确认边界。用户在当前请求中的明确指示优先于下列默认规则。

## 必须遵守的规则

- 除非用户明确指定其他下载位置，将所有软件安装程序和软件包下载到 `D:\My_Software\`。下载完成后确认实际保存路径。
- 如果目标版本需要付费，必须在开始下载前说明它是付费版本，并取得用户的明确确认。确认下载不等于授权购买、订阅或付款；这些操作需要用户另行明确授权。
- 安装前确定用户指定的安装位置。若请求中没有安装位置，不得自行采用安装器默认位置，应先向用户询问。
- 安装时使用用户指定的准确路径。若安装器不支持、自行忽略或无法采用该路径，立即停止安装流程并说明原因、安装器行为及当前状态；只有用户明确确认后，才能改用默认路径、其他路径或其他安装方式。
- 若发现安装器已经在失败或停止前写入文件、创建服务或做出其他系统更改，如实报告已发生的更改，不把部分安装描述为成功。

## 执行要点

1. 先识别软件名称、版本或版本类别、安装包来源，以及用户指定的安装位置；只补问会影响版本、付费确认或安装路径的缺失信息。
2. 版本是否付费不明确时，优先依据软件官方来源核实。无法可靠核实时，向用户说明不确定性，不要擅自下载可能需要付费的版本。
3. 下载前解析最终文件路径：优先采用用户本次指定的位置，否则采用 `D:\My_Software\`。不要因为浏览器或下载工具的默认设置而静默保存到其他目录。
4. 在运行安装器前，确认其是否支持目标目录参数或交互式目录选择。仅使用与当前安装包类型匹配的可靠参数，不猜测静默安装参数。
5. 安装后进行只读核验，确认安装是否成功以及实际安装位置是否与用户指定位置一致。
6. 向用户报告下载文件的实际位置、安装结果、实际安装位置，以及任何需要用户处理的后续步骤。

## 适用边界

- 本 Skill 适用于 Windows 桌面软件、安装器以及用于安装该软件的发行包。
- 普通项目依赖恢复或仓库内包管理不属于本 Skill，除非该操作会在系统或用户范围安装软件。
- 不要把“安装软件”的授权扩大为购买许可证、接受额外付费项目、修改无关系统配置或卸载现有软件。
